# 6. OneSecMail Provider

Implement an HTTP/API-based provider using `requests`.

Base API:

```text
https://www.1secmail.com/api/v1/
```

The provider should:

1. Generate an inbox identity.
2. Return its email address.
3. Poll for incoming messages until timeout.
4. Identify the Replit verification message.
5. Fetch the message body.
6. Extract the verification URL.
7. Store the verification URL.
8. Complete verification.

Handle network errors, invalid responses, malformed JSON, missing messages, and timeout cleanly.

Do not silently report success when verification was not actually observed.
