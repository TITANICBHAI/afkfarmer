## 2. Email architecture

Implement a provider abstraction:

```text
EmailProvider
├── OneSecMailProvider
└── TempMailOrgProvider
```

Configuration:

```python
REPLIT_PASSWORD = "12345678"

EMAIL_STRATEGY = "hybrid"
PRIMARY_EMAIL_API = "1secmail"
USER_CUSTOM_EMAIL = ""

TEMP_MAIL_PROVIDER = "temp-mail.org"
TEMP_MAIL_URL = "https://temp-mail.org/"

EMAIL_CHECK_TIMEOUT = 60
```

Priority:

```text
USER_CUSTOM_EMAIL
    ↓
primary API
    ↓
temp-mail.org fallback
```

If the user email is blank:

* `hybrid` → API first, temp-mail fallback
* `api` → API only
* `temp-mail.org` → browser temp-mail only

Do not remove the existing temp-mail.org implementation.
